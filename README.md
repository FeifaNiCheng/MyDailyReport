# MyDailyReport 📰

每日快报 — 自动化生成的 iOS 风格 HTML 页面。

## 内容

- 📋 每日计划列表提醒
- 🧩 Codex Skill 推荐卡片（含"对用户的帮助"分析）
- 🤖 AI 话题追踪（用 deep-crawler 抓取）
- 🛠️ Agent 对项目的帮助（Spring Boot/Vue3 开发流程等）
- 📚 个人知识库问答 AI 方案研究

## 技术栈

- 纯 HTML/CSS/JS，无依赖
- iOS 风格毛玻璃 + 流光边框 + 随机渐变背景
- localStorage 持久化删除记录
- 每日排版变体（variant-a/b/c）

## 自动化

由 Codex 自动化任务 `9-30-am` 每日 09:30 CST 自动生成并推送。

## 查看

直接在浏览器中打开 `index.html` 即可。
